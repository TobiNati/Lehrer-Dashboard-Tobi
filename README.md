# Lehrer-Dashboard Tobi

Abgespeckte Version des Lehrer-Dashboards für den Windows-Rechner in Firefox.
Sie läuft unter https://tobinati.github.io/Lehrer-Dashboard-Tobi/ und hat ihre
eigenen Daten, getrennt von der iPad-Version.

## Was drin ist

- Klassen mit Fächern, die du in den Einstellungen bearbeitest
- Schüler-Stammdaten: Name, Vorname, Betrieb, E-Mail, Telefon
- Klassenliste importieren: PDF, Scan oder Foto (mit Texterkennung), Excel, CSV oder Text
- Noten mündlich und schriftlich, Gewichtung 50/50, auch für die ganze Klasse auf einmal
- Stundenplan, Wochenplanung, Sitzplan, Kalender mit Ferien
- Notizen und ToDos je Schüler, Fehltage

Alle Daten liegen nur im Browser. Sichere sie regelmäßig über „Sicherung exportieren“.

## Starten

`make dev` startet einen lokalen Server auf http://localhost:8080.
`make help` zeigt alle Befehle.
